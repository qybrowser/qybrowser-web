软件介绍

启元指纹浏览器是一款专为跨境电商、自媒体矩阵运营设计的多账号防关联工具。每个浏览器环境拥有独立的指纹信息、Cookie 存储和代理配置，账号之间完全隔离，告别封号与关联风险。

核心功能模块： 环境管理 代理管理 成员管理 扩展中心 应用中心 开发者中心

常见问题

环境浏览器里可以访问哪些网站？▾
没有任何限制，只要网络可以访问的网站均可正常打开。访问海外站点（亚马逊、TikTok 等）时，需为该环境配置对应地区的海外代理 IP。
在 A 电脑登录账号后，切换到 B 电脑还需要重新登录吗？▾
取决于该环境是否开启了「同步用户信息」。开启后，Cookie 等登录信息会加密同步至云端，多台设备打开同一环境时将自动同步，无需重复登录。
用户信息同步到云端安全吗？▾
安全。所有同步内容在上传前均经过加密处理，数据托管于阿里云，服务端无法解密查看用户的明文信息。
软件提供代理 IP 吗？▾
软件本身不提供代理 IP，代理 IP 需用户自行向第三方购买。在新建环境的代理配置界面，我们提供了推荐购买渠道供参考。
不配代理 IP 可以正常使用吗？▾
可以使用，选择「本地直连」后，环境浏览器直接使用本机网络。但为保障账号安全，建议为每个账号配置独立的代理 IP，降低多账号共享同一 IP 带来的关联风险。
已在环境中登录账号后，还能修改指纹和代理 IP 吗？▾
技术上可以修改，但强烈不建议。修改指纹会导致设备信息突变，跨地区的 IP 切换也可能触发平台风控。对重要账号，建议做到「一账号一环境一 IP」，创建后保持稳定。
一个账号可以在多台设备上同时登录使用吗？▾
暂不支持，同一管理员账号同时只能在一台设备上登录。需要切换设备时，在新设备上登录后，旧设备会自动退出。
成员账号有哪些操作权限？▾
成员账号由管理员创建，可操作被授权的环境管理和代理管理功能。扩展中心、应用中心、开发者中心目前仅限管理员（Boss）账号使用。
会员过期后软件还能用吗？▾
可以继续使用，软件不会强制停用。到期后各项权益降级至免费版额度（环境数、成员数、矩阵用户数降至免费上限），应用中心和开发者中心暂停使用，续费后立即恢复所有权益。
最多可以同时打开几个浏览器窗口？▾
没有强制上限，取决于电脑硬件配置。普通配置的电脑建议同时打开 10～20 个，配置较高的电脑可达 20～30 个，超出配置上限可能出现卡顿。
应用任务最多可以同时运行几个？▾
最多同时运行 5 个任务。
任务的输出文件可以在多台设备上查看吗？▾
不可以，结果文件仅保存在执行任务的本地设备上，其他设备无法直接访问，需手动传输文件进行共享。
任务结果文件会长期保存吗？▾
不会。为避免占满本地磁盘，结果文件最多保留 7 天，到期后自动清除。请及时下载备份重要的采集数据。
